# Certificates for the sharp bound of the third logarithmic coefficient

This repository contains the companion computational files for the interval-arithmetic verification in the paper:

**The sharp bound for the third logarithmic coefficient of normalized close-to-convex functions**

## Files

- `verify_gamma3_standard_K_strict.py`: Python verification script.
- `certificate_G_intervals_strict.csv`: certificate for the one-dimensional verification of \(G(r)>0\).
- `certificate_final_strip_strict.csv`: certificate for the final strip verification.

## Requirements

The script requires Python 3 and `mpmath`.
